HOW TO FILL THIS OUT

01

Brand & Style

This is the ID block. The style number is your internal SKU root — make it short and consistent (brand initials + number). The season/drop tells the supplier which run this belongs to. Fill this first so every revision of the pack stays organized.

02

Fabric & Construction

Fabric content and GSM decide how the garment feels and what it costs. Heavyweight streetwear lives at 220–260 GSM. Write the exact blend (e.g. 100% cotton vs 80/20) — a supplier will substitute cheaper fabric if you leave this vague. List every construction detail: collar type, hem stitching, side seams. What isn’t written doesn’t get built.

03

Measurements

Take your favorite-fitting garment in this category, lay it flat, and measure each point with a tape. Chest: armpit to armpit, doubled. Length: highest shoulder point to hem. Sleeve: shoulder seam to cuff. Fill every size you’ll sell — suppliers grade from your base size, so get Medium right first. Allow ±0.5″ tolerance.

04

Print / Embroidery Specs

Name the exact method — screen print, DTG, embroidery, puff — because each has different cost, feel, and minimums. Placement must be specific (“full front, 3″ below collar” beats “front”). Give print size in inches and list every ink/thread color. Reference your artwork file by name so there’s zero confusion about which version to print.

05

Labels & Packaging

The neck label is what turns a blank into your brand — spec the material (woven damask, printed satin), colors, and where the size goes. Hang tags and inserts are your unboxing moment: write exactly what’s included. Packaging gets one line, but it’s the first thing the customer touches.

06

Supplier Notes

One supplier per tech pack. Record the MOQ, the unit cost you were quoted, and the lead time in writing — this is what you hold them to. Track sample status here so you always know where each style stands. Notes are for anything you’d forget in two weeks: backup suppliers, negotiated terms, quality flags.

07

Send it

Export this page to PDF (Print / Save PDF button) and send it with your artwork files. When the sample comes back wrong, you point at the line in the pack — that’s the whole point. A supplier who gets a real tech pack treats you like a real brand.
